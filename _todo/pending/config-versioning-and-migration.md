# Configuration File Versioning and Migration System

## Original Objective
Config.toml files should display the keecas version number they were generated with. Implement a schema migration system to handle breaking configuration changes, alerting users about deprecations and automatically migrating old preferences to new style when possible.

## Context
- Current config system: TOML-based, hierarchical (global/local)
- Configuration locations:
  - Global: `~/.keecas/config.toml`
  - Local: `<project>/.keecas/config.toml`
- CLI commands: `keecas config init`, `keecas config show`, etc.
- No version tracking currently implemented
- No migration system for breaking changes
- Preparing for v1.0.0 release

## Implementation Plan

### 1. Add Version Tracking to Config Files

**Modification**: Update `src/keecas/config.py` to inject version metadata as comments

**Config file structure**:
```toml
# Generated by keecas v1.0.0
# Schema version: 1.0.0
# Created: 2025-10-03T12:34:56
# Last updated: 2025-10-03T14:22:10

# User configuration
language = "en"
katex = false
eq_prefix = "eq-"

[display]
default_float_format = ".3f"
pint_default_format = ".3f~P"

[latex.environments.custom]
separator = "&"
line_separator = " \\\\[0.5em]\n "
```

**Implementation approach**:
- Version metadata stored only in header comments (not in TOML structure)
- Parser reads comments on load to extract version info
- Simpler config structure - no `[metadata]` section cluttering user config
- Migration system reads header comments to determine current schema version

**Metadata extraction**:
```python
def extract_metadata_from_comments(config_path: Path) -> dict:
    """Extract version metadata from config file header comments."""
    metadata = {
        "config_version": "0.1.0",  # Default for old configs
        "keecas_version": "unknown",
        "generated_at": None,
        "last_modified": None
    }

    with open(config_path) as f:
        for line in f:
            if not line.startswith('#'):
                break  # Stop at first non-comment

            if 'Schema version:' in line:
                metadata['config_version'] = line.split(':')[1].strip()
            elif 'Generated by keecas v' in line:
                metadata['keecas_version'] = line.split('v')[1].strip()
            elif 'Created:' in line:
                metadata['generated_at'] = line.split(':', 1)[1].strip()
            elif 'Last updated:' in line:
                metadata['last_modified'] = line.split(':', 1)[1].strip()

    return metadata
```

def migrate_0_1_to_1_0(old_config: Dict) -> Dict:
    """Migrate config from 0.1.x to 1.0.0

    IMPORTANT: All user-customized values MUST be preserved during migration.
    Only transform structure/location, never lose user data.
    """
    new_config = old_config.copy()  # Preserves ALL user values as starting point

    # RENAME: Move pint_default_format to display section (preserves user value)
    if "pint_default_format" in new_config:
        user_value = new_config.pop("pint_default_format")  # Extract user's value
        if "display" not in new_config:
            new_config["display"] = {}
        new_config["display"]["pint_default_format"] = user_value  # Preserve it
        print(f"✓ Migrated 'pint_default_format' → 'display.pint_default_format' (value: {user_value})")

    # DEPRECATED: Warn but preserve for now (remove in v2.0.0)
    if "sep" in new_config:
        warn(
            "`sep` is deprecated. Use `config.latex.environments.align.separator` instead. "
            "This key will be removed in keecas v2.0.0",
            DeprecationWarning
        )
        # Keep the value for now - don't auto-migrate (too complex)

    # REMOVED WITH CONVERSION: float_precision → display.default_float_format
    if "float_precision" in new_config:
        precision = new_config.pop("float_precision")  # Extract user's precision value
        if "display" not in new_config:
            new_config["display"] = {}
        # Convert numeric precision to format string, preserving user intent
        new_config["display"]["default_float_format"] = f".{precision}f"
        print(f"✓ Converted 'float_precision={precision}' → 'display.default_float_format=\".{precision}f\"'")

### 3. Implement Migration Engine

**File**: `src/keecas/config_migration.py`

**Migration engine logic**:
```python
from packaging import version
from warnings import warn
from .config_schema import SCHEMAS

class ConfigMigration:
    @staticmethod
    def needs_migration(config_version: str, current_version: str) -> bool:
        """Check if config needs migration"""
        return version.parse(config_version) < version.parse(current_version)

    @staticmethod
    def get_migration_path(from_version: str, to_version: str) -> List[str]:
        """Get ordered list of schema versions to migrate through"""
        all_versions = sorted(SCHEMAS.keys(), key=version.parse)
        start_idx = all_versions.index(from_version)
        end_idx = all_versions.index(to_version)
        return all_versions[start_idx + 1 : end_idx + 1]

    @staticmethod
    def migrate(config_data: Dict, from_version: str, to_version: str) -> Dict:
        """Migrate config through all intermediate versions"""
        migration_path = ConfigMigration.get_migration_path(from_version, to_version)

        current_config = config_data.copy()
        for target_version in migration_path:
            schema = SCHEMAS[target_version]

            # Warn about deprecated keys
            for key in schema.deprecated_keys:
                if key in current_config:
                    warn(
                        f"Config key '{key}' is deprecated as of keecas {target_version}. "
                        f"See migration guide for alternatives.",
                        DeprecationWarning
                    )

            # Handle removed keys
            # NOTE: Custom migration_fn should handle value conversion BEFORE removal
            # This section only removes keys that truly have no migration path
            for key in schema.removed_keys:
                if key in current_config:
                    # Only warn if the custom migration didn't already handle it
                    warn(
                        f"Config key '{key}' was removed in keecas {target_version}. "
                        f"Check migration guide for replacement options.",
                        UserWarning
                    )
                    current_config.pop(key)

            # Apply renaming
            for old_key, new_key in schema.renamed_keys.items():
                if old_key in current_config:
                    # Handle nested keys (e.g., "display.pint_default_format")
                    parts = new_key.split('.')
                    if len(parts) > 1:
                        # Create nested structure
                        current_level = current_config
                        for part in parts[:-1]:
                            if part not in current_level:
                                current_level[part] = {}
                            current_level = current_level[part]
                        current_level[parts[-1]] = current_config.pop(old_key)
                    else:
                        current_config[new_key] = current_config.pop(old_key)

                    print(f"✓ Migrated '{old_key}' → '{new_key}'")

            # Run custom migration function
            if schema.migration_fn:
                current_config = schema.migration_fn(current_config)

            # Metadata will be updated in header comments during save
            # No need to modify config_data structure

        return current_config
```

### 4. Update Config Class to Handle Migrations

**Modification**: `src/keecas/config.py`

**Key changes**:
```python
from .config_migration import ConfigMigration
from . import __version__

class KeecasConfig:
    def load(self, config_path: Path) -> None:
        """Load config with automatic migration"""
        # Extract metadata from header comments
        metadata = self._extract_metadata_from_comments(config_path)
        config_version = metadata.get("config_version", "0.1.0")
        current_version = self._get_current_schema_version()

        # Load actual config data
        data = toml.load(config_path)

        # Check if migration needed
        if ConfigMigration.needs_migration(config_version, current_version):
            print(f"⚠️  Config migration required: {config_version} → {current_version}")

            # Backup old config
            backup_path = config_path.with_suffix(".toml.backup")
            shutil.copy(config_path, backup_path)
            print(f"📦 Backup created: {backup_path}")

            # Perform migration
            try:
                migrated_data = ConfigMigration.migrate(data, config_version, current_version)
                self._update_from_dict(migrated_data)

                # Save migrated config (preserves metadata in comments)
                self.save(config_path, created_at=metadata.get("generated_at"))
                print(f"✓ Config migrated successfully to {current_version}")

            except Exception as e:
                print(f"❌ Migration failed: {e}")
                print(f"   Restore from backup: {backup_path}")
                raise

        else:
            self._update_from_dict(data)

    def save(self, config_path: Path, created_at: str | None = None) -> None:
        """Save config with version metadata in header comments"""
        data = self.to_dict()
        schema_version = self._get_current_schema_version()
        now = datetime.now().isoformat()

        # Determine creation timestamp
        if created_at is None:
            # Try to preserve existing creation time from file
            if config_path.exists():
                existing_metadata = self._extract_metadata_from_comments(config_path)
                created_at = existing_metadata.get('generated_at')
            # If still None, this is a new file
            if created_at is None:
                created_at = now

        # Write with header comments containing metadata
        with open(config_path, 'w') as f:
            f.write(f"# Generated by keecas v{__version__}\n")
            f.write(f"# Schema version: {schema_version}\n")
            f.write(f"# Created: {created_at}\n")
            f.write(f"# Last updated: {now}\n\n")
            toml.dump(data, f)

    @staticmethod
    def _extract_metadata_from_comments(config_path: Path) -> dict:
        """Extract version metadata from config file header comments."""
        metadata = {
            "config_version": "0.1.0",  # Default for old configs without header
            "keecas_version": "unknown",
            "generated_at": None,
            "last_modified": None
        }

        if not config_path.exists():
            return metadata

        with open(config_path) as f:
            for line in f:
                if not line.startswith('#'):
                    break  # Stop at first non-comment line

                if 'Schema version:' in line:
                    metadata['config_version'] = line.split(':', 1)[1].strip()
                elif 'Generated by keecas v' in line:
                    metadata['keecas_version'] = line.split('v')[1].strip()
                elif 'Created:' in line:
                    metadata['generated_at'] = line.split(':', 1)[1].strip()
                elif 'Last updated:' in line:
                    metadata['last_modified'] = line.split(':', 1)[1].strip()

        return metadata

    @staticmethod
    def _get_current_schema_version() -> str:
        """Get current schema version (highest in registry)"""
        from .config_schema import SCHEMAS
        from packaging import version
        return max(SCHEMAS.keys(), key=version.parse)
```

### Design Decision: Version Metadata in Comments

**Approach**: All metadata stored in header comments (not in TOML structure)

**Benefits**:
- Keeps TOML structure clean for users
- No `[metadata]` section cluttering user config
- Metadata is read-only (extracted during load, regenerated during save)
- Old configs without headers get default version "0.1.0"
- Comment parsing is simple and robust (stops at first non-comment line)

**Creation Timestamp Preservation**:
When saving config, the `save()` method:
1. If `created_at` explicitly provided (e.g., during migration) → use it
2. If file exists, extract `generated_at` from existing header → preserve it
3. If new file, use current timestamp → set initial creation time

This ensures:
- Migration preserves original creation timestamp
- Manual saves (e.g., after `config.language = 'it'`) preserve creation time
- New configs get proper creation timestamp
- "Last updated" always reflects most recent save

### User Value Preservation During Migration

**Core principle**: Migration NEVER loses user-customized values

**How it works**:
1. Migration starts with `new_config = old_config.copy()` (all user values preserved)
2. Custom migration functions transform values, not discard them
3. Unknown keys (not in any schema list) automatically preserved
4. Backup created before migration for safety
