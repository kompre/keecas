┌───────────────────────────────────────────────────────────────────┐
│ THE 3 ESSENTIAL COMMANDS                                          │
└───────────────────────────────────────────────────────────────────┘

1. Auto-fix code (adds trailing commas automatically):
   → uv run ruff check --fix src/ tests/

2. Check docstring code blocks:
   → uv run python scripts/lint_docstring_code.py src/keecas/*.py

3. Run tests:
   → uv run pytest tests/


┌───────────────────────────────────────────────────────────────────┐
│ MAKEFILE SHORTCUTS (if you have 'make' installed)                │
└───────────────────────────────────────────────────────────────────┘

make fix       ← Auto-fix code style
make lint-docs ← Check docstring code
make test      ← Run tests
make check     ← Run everything


┌───────────────────────────────────────────────────────────────────┐
│ WHAT TRAILING COMMAS LOOK LIKE                                   │
└───────────────────────────────────────────────────────────────────┘

❌ WRONG (missing comma):
my_list = [
    1,
    2,
    3      ← No comma here!
]

✅ CORRECT (with trailing comma):
my_list = [
    1,
    2,
    3,     ← Comma here!
]


┌───────────────────────────────────────────────────────────────────┐
│ VS CODE AUTO-FIX ON SAVE (EASIEST!)                              │
└───────────────────────────────────────────────────────────────────┘

1. Install Ruff extension in VS Code
2. Settings are already configured (.vscode/settings.json)
3. Just save your file (Ctrl+S) - auto-fixes everything!


┌───────────────────────────────────────────────────────────────────┐
│ TYPICAL WORKFLOW                                                  │
└───────────────────────────────────────────────────────────────────┘

1. Write code
2. uv run ruff check --fix src/ tests/
3. uv run python scripts/lint_docstring_code.py src/keecas/*.py
4. Fix docstring issues manually (if any)
5. uv run pytest tests/
6. git commit
