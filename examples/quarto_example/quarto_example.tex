\section{How to use keecas in a Quarto
document}\label{how-to-use-keecas-in-a-quarto-document}

This example demonstrates key features of \texttt{keecas} for symbolic
and units-aware calculations in a Quarto document.

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, colback=white, titlerule=0mm, breakable, opacityback=0, colbacktitle=quarto-callout-note-color!10!white, toprule=.15mm, colframe=quarto-callout-note-color-frame, toptitle=1mm, leftrule=.75mm, bottomrule=.15mm, left=2mm, bottomtitle=1mm, title=\textcolor{quarto-callout-note-color}{\faInfo}\hspace{0.5em}{Note}, opacitybacktitle=0.6, rightrule=.15mm, coltitle=black]

If the rendering engine is \texttt{KaTeX} (i.e.~Jupyter notebook), the
label command \texttt{\textbackslash{}label\{\}} will result in a
\texttt{ParseError}. The latex code will work when rendering by
\texttt{quarto\ render}, but since you may want to see the result before
rendering the document, an option to disable the
\texttt{\textbackslash{}label\{\}} command is provided.

When rendering with \texttt{quarto} you can have two config:

\begin{itemize}
\tightlist
\item
  if \texttt{qmd} files, then everything is fine
\item
  if \texttt{ipynb} files, then pass the \texttt{-\/-execute} flag to
  \texttt{quarto\ render} to rerender the notebook
\end{itemize}

\end{tcolorbox}

\subsection{Automatic Dependency
Ordering}\label{automatic-dependency-ordering}

Using \texttt{pc.subs} will automatically order the substitutions pairs
topologically, so you don't have to order them yourself (default
\texttt{sympy} behavior). For example, let's define some mappings in any
order:

\begin{align}
    \left\{\begin{aligned}
x & = y^{2}  \\[8pt]
 y & = 1 + a  \\[8pt]
 a & = 3 
    \end{aligned}\right.
\end{align}

If we use the default behavior of \texttt{sympy}'s \texttt{subs} method
(unsorted substitutions) we get:

\begin{align}
    \left\{\begin{aligned}
x & = \left(1 + a\right)^{2} & \quad\text{partially evaluated}  \\[8pt]
 y & = 4 &    \\[8pt]
 a & = 3 &   
    \end{aligned}\right.
\end{align}

While the default behavior of \texttt{pc.subs} is to sort the
substitutions:

\begin{align}
    \left\{\begin{aligned}
x & = 16 & \quad\text{fully evaluated}  \\[8pt]
 y & = 4 &    \\[8pt]
 a & = 3 &   
    \end{aligned}\right.
\end{align}

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, colback=white, titlerule=0mm, breakable, opacityback=0, colbacktitle=quarto-callout-note-color!10!white, toprule=.15mm, colframe=quarto-callout-note-color-frame, toptitle=1mm, leftrule=.75mm, bottomrule=.15mm, left=2mm, bottomtitle=1mm, title=\textcolor{quarto-callout-note-color}{\faInfo}\hspace{0.5em}{Note}, opacitybacktitle=0.6, rightrule=.15mm, coltitle=black]

\texttt{pc.subs} automatically converts objects to \texttt{sympy}
expressions before substitution. In the example above, \(a\) maps to the
Python \texttt{int} value \texttt{3}. When piping \texttt{int} through
\texttt{pc.subs}, it works seamlessly. If you used \texttt{sympy}'s
\texttt{subs()} method directly, you'd get an error since \texttt{int}
objects don't have a \texttt{subs()} method. You'd need to write
\texttt{S(rhs).subs(...)} to explicitly convert first.

\end{tcolorbox}

\subsection{Common Pitfalls}\label{common-pitfalls}

\subsubsection{Pitfall 1: LaTeX vs Plain Symbol
Notation}\label{pitfall-1-latex-vs-plain-symbol-notation}

Symbols are compared by their string representation, so LaTeX and plain
notation create different objects:

$\displaystyle \sigma_{Sd}$

$\displaystyle \sigma_{Sd}$

\begin{verbatim}
Are they equal? False
\end{verbatim}

\subsubsection{\texorpdfstring{Pitfall 2: Using \texttt{vals} dict in
\texttt{pc.subs}}{Pitfall 2: Using vals dict in pc.subs}}\label{pitfall-2-using-vals-dict-in-pc.subs}

While maintaining a global \texttt{vals} dict for evaluated results can
be useful, passing it to \texttt{pc.subs} will overwrite expressions
with already evaluated values, preventing recalculation when parameters
change.

\begin{align}
x & = 2 &    \\[8pt]
 y & = x + 1 & = 3.0  \\[8pt]
 z & = y^{2} & = 9.0 
\end{align}

Now update the parameter and see the problem:

\begin{align}
x & = 3 &    \\[8pt]
 y & = 4 & \quad\text{$\textcolor{green}{\left[=4\quad \textbf{VERIFICATO}\right]}$}  \\[8pt]
 z & = 9.0 & \quad\text{$\textcolor{red}{\left[\neq16\quad \textbf{NON VERIFICATO}\right]}$} 
\end{align}

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, colback=white, titlerule=0mm, breakable, opacityback=0, colbacktitle=quarto-callout-tip-color!10!white, toprule=.15mm, colframe=quarto-callout-tip-color-frame, toptitle=1mm, leftrule=.75mm, bottomrule=.15mm, left=2mm, bottomtitle=1mm, title=\textcolor{quarto-callout-tip-color}{\faLightbulb}\hspace{0.5em}{Tip}, opacitybacktitle=0.6, rightrule=.15mm, coltitle=black]

\textbf{Recommendation}: Only pass \texttt{vals} to \texttt{pc.subs} if
you're certain no dependent expressions need updating.

\end{tcolorbox}
